# Tic-Tac-Toe Game

A simple, modern web-based Tic-Tac-Toe game built with vanilla HTML, CSS, and JavaScript.

## Features

- 🎮 Two-player gameplay (X and O)
- 🎨 Modern, responsive UI with gradient styling
- ✨ Smooth animations and hover effects
- 🏆 Win detection and draw handling
- 🔄 Reset button to start a new game
- 📱 Mobile-friendly design

## How to Play

1. Open `index.html` in your web browser
2. Players take turns clicking on empty cells
3. First player to get 3 in a row (horizontal, vertical, or diagonal) wins
4. Click "Reset Game" to start a new game

## Game Rules

- Players alternate between X and O
- Players can only place their mark on empty cells
- The first player to place three marks in a row wins
- If all cells are filled and no winner is determined, it's a draw

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Gradients)
- Vanilla JavaScript (ES6)
